# EtuBibliotheque

Projet 2 — Testez et améliorez une application existante (OpenClassrooms, Expert DevOps).

- `back-end/` : API Spring Boot (voir `back-end/README.md`)
- `front-end/` : application Angular (voir `front-end/README.md`)
- `rapports/` : rapports de couverture — `back-end-jacoco/index.html` (JaCoCo) et `front-end-jest/` (Jest)

Tests : `./mvnw verify` dans `back-end/`, `npm test` et `npx cypress run` dans `front-end/`.
